# 결정 기록

개발문서에서 "결정이 필요한 항목"으로 남겨 둔 것들을 MVP 구현에서 어떻게 정했는지 기록한다. 모두 `src/config.ts`의 값이나 작은 코드 변경으로 바꿀 수 있다. 바꾸면 이 문서도 함께 고친다.

| D-2 | 구속의 효과 | **5일차 지목의 준비 단계일 뿐**이다. 사건·단서에 영향을 주지 않고, 5일차 처형 화면에서 구속한 사람이 미리 선택된다. | `src/core/game.ts` |

## 밸런스 관찰 (1만 판 시뮬레이션)

`npm run test:sim` 실행 시 콘솔에 출력된다. 첫 측정값:

- 민간인은 5명에게 거의 고르게 배정된다 (각 약 19~21%).
- **사건 4건이 모두 공개되었다고 가정할 때**, 1~2일차 힌트(8개)만으로 해가 하나로 좁혀지는 판이 약 89%다.
  실제로는 사건이 하루에 하나씩 공개되므로 체감 난이도는 이보다 높지만, 전체적으로 쉬운 편일 수 있다.
- 베타 테스트(9장 5단계)에서 너무 쉽다는 의견이 많으면: 총 힌트 수(`totalHints`)를 줄이거나, 하루 질문 포인트를 줄이거나,
  주술사 거짓 힌트(D-3 변경)를 후속 버전에서 검토한다. 힌트를 줄일 때도 시뮬레이션이 해의 유일성을 계속 검사한다.
